# Barbets Duet Platform Expansion

## Vision
Transform the Barbets Duet web presence from a single-page showcase into a comprehensive global learning and impact platform. The platform will serve as the digital hub for a network of learning sites, connecting ecosystem restoration with sustainable economic activities and community empowerment.

## Goals
- **Expand Content Architecture**: Implement a multi-page structure covering "About Us", "Our Work", "Community", "Resources", and "Get Involved".
- **Dynamic Learning Sites**: Build a robust system for showcasing and applying to be a "Learning Site".
- **Community Engagement**: Establish a partner network and membership system.
- **Resource Hub**: Centralize educational programs, research, and tools.

## Key Requirements
- **Integration**: All new pages must integrate seamlessly with the existing Next.js 15 and Firebase setup.
- **Aesthetics**: Maintain the high-fidelity, "Clinical Luxury" design system.
- **Performance**: Ensure fast load times despite rich interactive elements (3D/Globe).
- **SEO**: Implement best practices across all new routes.
- **Scalability**: Design data structures in Firestore to handle a growing network of sites and members.

## Architectural Evolution
We are following a **"Lean First, Relational Second"** strategy. 
- **Phase 1-15**: Stick to Firebase for speed and zero-infra overhead.
- **Monitoring**: Every 2 milestones, we will evaluate if the "Pivot Triggers" defined in `ARCHITECTURE.md` have been met.
